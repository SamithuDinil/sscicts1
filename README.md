# SSCICTS

Next.js 16 site for the Sri Sumangala College ICT Society competitions.

## Run

npm install
npm run dev

Production: npm run build && npm start

## Edit content

All text, competitions, team, gallery and the countdown date live in src/lib/data.ts.
Copy .env.example to .env.local to override the site URL and EmailJS keys.

## Deploy

Push to GitHub and import the repo in Vercel. No extra configuration needed.
